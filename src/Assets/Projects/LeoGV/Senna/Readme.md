# LeoGV – Project Senna Control Board
An advanced vehicle control and communication board designed for LeoGV – Project Senna, integrating high-performance processing, power management, motor control, and robust communication interfaces to support autonomous and electric vehicle subsystems.

## Features
### Main Processing Unit
- Central MCU-based architecture for real-time control and system coordination.
- Dedicated debugging and programming interfaces for firmware development.

### Communication Interfaces
- CAN Bus interface for in-vehicle communication and distributed control.
- Isolated communication sections to enhance noise immunity and reliability.
- Standard headers for integration with external modules and sensors.

### Power Management
- Wide input voltage support with onboard DC-DC conversion and LDO regulation stages.
- Separate regulated rails for logic and power stages.

### Motor & Actuator Control
- Integrated motor driver interfaces for traction and auxiliary systems.
- PWM-based control architecture with feedback monitoring.
- Current sensing and protection mechanisms for safe operation.

### Protection & Safety
- Overcurrent and short-circuit protection.
- Reverse polarity protection.
- ESD protection on external communication and power lines.

### Indicators & Debugging
- Status LEDs for power, communication, and fault indication.
- Multiple test points for signal probing and diagnostics.
- Clearly labeled connectors for simplified system integration.

## Applications
- Electric Vehicle Subsystems
- Autonomous Ground Vehicle Platforms
- Robotics & Mobility Projects
- Distributed Automotive Control Systems

This board serves as the central control unit of Project Senna, combining processing, communication, power regulation, and protection features into a single robust platform suitable for intelligent vehicle and robotics applications.
