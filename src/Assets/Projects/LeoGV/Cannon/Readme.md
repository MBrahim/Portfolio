# DRV8818 Stepper Motor Driver
A compact dual H-Bridge stepper motor driver based on Texas Instruments DRV8818, designed to control bipolar stepper motors with integrated current regulation, microstepping capability, and built-in protection features for reliable motion control applications.

## Features
### Dual H-Bridge Driver
- Integrated dual H-Bridge architecture for driving one bipolar stepper motor or two DC motors.
- Wide VM supply range.
- Adjustable current regulation.

### Microstepping & Control
- STEP and DIR interface for easy motion control.
- Multiple microstepping modes configurable via MODE pins.
- ENABLE and nSLEEP pins for low-power control.

### Current Regulation
- Internal current chopping with programmable current limit.
- VREF input for setting maximum motor current.
- Integrated current sensing.

### Protection
- Overcurrent protection (OCP).
- Thermal shutdown (TSD).
- Undervoltage lockout (UVLO).
- Fault indication via nFAULT pin.

### Outputs
- Motor outputs exposed through terminal blocks (AOUT1, AOUT2, BOUT1, BOUT2).
- Designed for stable switching and reduced EMI.

### Indicators & Test Points
- Status LEDs for power and fault indication.
- Dedicated test points for monitoring control and feedback signals.

## Applications
- Bipolar Stepper Motor Control
- Precision Positioning Systems
- Robotics and Automation
- Printers and CNC Systems
- Industrial Motion Control

This board provides a reliable and efficient stepper motor driving solution using the DRV8818, offering configurable microstepping, adjustable current limiting, and comprehensive protection features suitable for compact and precise motion control systems.
